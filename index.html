How the similarity score works

  1. Numeric features are standardized so none dominates the others.
  2. We compute a weighted Euclidean distance D = sqrt(sum(w_i (x_i - y_i)^2)) between the reference site and each Earth site.
  3. Geology is a category, not a number, so it is compared with a rock-type similarity table.
  4. Distance becomes a score: S = 100 * exp(-D / tau). It is a similarity index, not a statistical probability.

Terrain similarity does not mean a site is suitable for a landing simulation. Atmosphere, temperature and radiation are not modeled.
