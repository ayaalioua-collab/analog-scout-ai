03
SIMILARITY ENGINE

From planetary data to Earth analogs.

The system evaluates five numerical terrain properties to identify the closest Earth analogs for each selected lunar or Martian reference site.

  1. Feature selection

    Five numerical features are used: slope, surface roughness, albedo, thermal inertia, and local relief. Each feature receives an equal initial contribution to the comparison.

  2. Min-Max normalization

    All 48 sites are used to normalize each numerical feature to a common scale between 0 and 1. This prevents differences in measurement units from dominating the analysis.

    xi′ = xi − xmin xmax − xmin
  3. Equal feature weighting

    Each of the five features receives an initial weight of 20%. The weighted Euclidean distance measures the numerical difference between the reference site and each Earth candidate.

    wi = 15 = 0.20
  4. Missing data handling

    Missing measurements are not treated as zero. Only features available for both sites are compared. Their weights are renormalized so that the active weights sum to 1. Here, A represents the set of shared available features.

    wi* = wi ∑ j∈A wj
  5. Weighted Euclidean distance

    The distance is calculated from the squared normalized differences across all shared features, using the renormalized weights.

    D = ∑ i∈A wi* ( xi′ − yi′ ) 2
  6. Similarity ranking

    The calculated distance is converted into a similarity index. The five highest-scoring Earth candidates are presented as the closest analogs.

    S = 100 e −D

    Difference is calculated as:

    Difference = 100 − S

    • Scientific interpretation: Similarity scores are comparative indices, not probabilities or measures of landing suitability. The analysis is based on the five selected numerical terrain features. Atmospheric conditions, radiation, temperature and mission-specific engineering constraints are not included in the similarity calculation.
